
# 🎮 Hangman Game – Python

## 📌 Project Overview

This is a simple text-based Hangman game developed using Python as part of my CodeAlpha Python Programming Internship.

The game allows players to guess a randomly selected word one letter at a time. Players have a maximum of six incorrect guesses before the game ends.

## 🎯 Features

- Random word selection from a predefined list of five words.
- Letter-by-letter word guessing.
- Maximum of six incorrect guesses.
- Displays correctly guessed letters.
- Tracks previously guessed letters.
- Prevents repeated guesses.
- Validates user input.
- Displays win and game-over messages.
- Allows players to replay the game without restarting the program.

## 🎮 How to Play

1. Run the program.
2. A random word will be selected.
3. Enter one letter at a time to guess the hidden word.
4. Correct guesses reveal the matching letters.
5. Incorrect guesses reduce your remaining attempts.
6. You have six incorrect guesses before the game ends.
7. Choose whether to play another round when prompted.
